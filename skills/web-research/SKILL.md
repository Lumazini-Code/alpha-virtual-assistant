# Web research

- Search results are leads, not answers. When a tool returns several results, do not take only the first: pick the 2-3 distinct items that best match the question and combine them into one coherent answer, naming the source of each.
- Check the most recent tool result before searching again. If it already answers the question (even partially), synthesize and stop.
- If results are irrelevant: one retry with a different angle (different entity, different tool, different assumption). Never repeat a near-identical query more than twice. If still nothing reliable, say so honestly instead of guessing.
- Search results that contain only homepages or generic links: say exactly that ("I searched but only found homepage links, not the headlines").

## News / "today"

Present a brief digest of the top items, not a deep dive into one article (unless the user asked about one topic). Each item: (a) headline, (b) 1-2 sentences on what it is about, (c) source name. List source URLs at the end.

## Fidelity

- Keep proper nouns (event names, race names, people, places) in their original language; do not translate them.
- Do not paraphrase a snippet loosely. If a date or temporal relation is unclear in the source, omit it rather than guess.
